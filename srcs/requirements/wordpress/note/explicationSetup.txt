version facile
sleep 10 = attend 10 sec avant d'executer wordpress car wordpress demarre en mm tps que MariaDB
si wordpress essaie de se connecter trop tot = erreur connexion DB

version complexe qui permet d'optimiser le tps, car ca peut prendre moins de 10 sec ou +
while ! mysqladmin ping -h mariadb -u${MYSQL_USER} -p${MYSQL_PASSWORD} --silent;
-h mariadb = nom du service Docker
--silent = ne rien afficher
! = tant que ça ne répond pas
cad tant que mariadb me repond pas, attendre 2 sec

wp config create \
	--dbname=$MYSQL_DATABASE \
	--dbuser=$MYSQL_USER \
	--dbpass=$MYSQL_PASSWORD \
	--dbhost=mariadb:3306 \
	--allow-root
cree automatiquement le fichier /var/www/html/wp-config.php.
ce fichier contient : nom de la base, utilisateur, mot de passe, hote (mariadb:3306)
donc wordpress peut se connecter a mariadb

wp core install \
	--url=$DOMAIN_NAME \
	--title="Inception" \
	--admin_user=$WP_ADMIN_USER \
	--admin_password=$WP_ADMIN_PASSWORD \
	--admin_email=$WP_ADMIN_EMAIL \
	--skip-email \
	--allow-root
installe wordpress dans la base de donnees : cree les tables SQL, definit l'admin, configure le site, met le titre

php-fpm -F = lance php-fpm
-F = foreground (obligatoire dans docker)
le container reste actif
sans ca, le container s'arrete immediatement
